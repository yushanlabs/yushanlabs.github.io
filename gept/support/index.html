有問題或建議，歡迎來信：fsrsmemory@gmail.com
來信時請告訴我們 iPhone 或 iPad 的型號、iOS 版本，以及發生問題的畫面。我們會盡快回覆。

常見問題

可以免費試用嗎？

可以。每個級別都可以免費學 200 個字，學過的字會一直照常複習。

價格是多少？是訂閱嗎？

不是訂閱，一次買斷。初級 NT$150、中級 NT$250、中高級 NT$350，三級全套 NT$590。購買後可以透過 Apple「家人共享」給家人使用。

換手機或重新安裝後，要怎麼找回購買？

在 ⋯ 選單按「購買／恢復購買」→「恢復購買」，用購買時的 Apple ID 就能找回，不用再付費。

發音檔要怎麼下載？

試用字的發音內建在 App 裡。購買後會自動下載那個級別的發音檔（約 50–60 MB），建議連上 Wi-Fi。下載完就能離線使用；下載完成前會先用 iPhone 內建的語音。

換手機，學習進度怎麼帶過去？

進度只存在這台裝置上。請在舊手機的 ⋯ 選單按「匯出／匯入進度」→ 匯出，把檔案存到「檔案」App 或傳給自己；再到新手機用同一個地方匯入。

英翻中和拼字有什麼不同？

兩邊是分開的記憶曲線：新字從英翻中開始，答對過的字可以在「拼字練習」裡練。一個字可以英翻中很熟、拼字還不會，兩邊的錯誤互不影響。

為什麼有時候新字變少？

到期要複習的字比較多時，App 會先讓你複習，暫時減少新字，避免越積越多。多做幾回合就會恢復。

錯字本和待加強有什麼不同？

「待加強」是最近常錯、還沒記牢的字，記牢就會離開；「錯字本」保留所有答錯過的字，可以分批印成複習版或考試版 PDF。

關於

單字範圍參考全民英檢（GEPT）初級、中級、中高級。本 App 為個人開發的學習工具，與財團法人語言訓練測驗中心（LTTC）無關。發音為 Microsoft Azure AI 合成的美式發音；Microsoft 與 Azure 是 Microsoft Corporation 的商標。
