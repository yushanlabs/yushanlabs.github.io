背單字最大的問題，是不知道自己現在在哪裡。

學測英文的單字範圍是大考中心《高中英文參考詞彙表》。我們整理了 83 到 115 年的歷屆學測詞彙題，新課綱（111 年起）的正解有 88% 落在第 3 到 5 級。與其拿起單字書從 A 背起，不如先知道每一級你已經認得多少，把時間花在還不熟的那一級。

    這一輪不會的字

      方法與驗證

      1. 分層隨機抽樣（stratified random sampling）

      把詞彙表當成母體，依級別分成 6 層，第 h 級有 Nh 個字（約 1,000）。每層各隨機抽 nh 個字，用樣本比例 p̂h 估計整層的認得比例 ph：

      T̂ = Σ Nh · p̂h　（h = 1…6）

      各層難度差異很大、層內相對一致，正是分層抽樣最有效的情況：如果 6,136 字混在一起做簡單隨機抽樣，可能剛好抽到太多簡單字或太多難字；分層後每一級都固定 10 題，層與層之間的差異不再進入誤差，估計量的變異數比簡單隨機抽樣小。

      2. 猜題校正與不偏性（correction for guessing）

      每一題的得分記為 X：答對 X = 1，答錯 X = −1/3，選「不知道」X = 0。假設認得的字一定答對，不認得的字有 g 的機率去猜（四選一，猜對機率 1/4），其餘選「不知道」。那麼一題的期望得分是：

      E[X] = p + (1 − p)·g·¼·1 + (1 − p)·g·¾·(−⅓)
      　　 = p + (1 − p)·g·(¼ − ¼) = p

      猜對多得的分數，剛好被猜錯扣的分數抵銷。不管你多常猜（g 是多少），每題得分的期望值都等於你真正認得的比例 p，所以 p̂h = 這一級 X 的平均，是 ph 的不偏估計量（unbiased estimator），T̂ 也就是總字數的不偏估計量。猜題不會讓平均結果變高，只會讓變異數變大。

      所以加總時每層用原始的 p̂，即使某一層略小於 0 也照算，最後總數才限制在 0 以上；如果每層先截斷在 0–100%，會系統性地高估（模擬中亂猜者平均高估 50–200 字）。結果頁的各級長條為了好讀才截斷顯示。

      3. 標準誤（standard error）

      同一級的題目互相獨立，所以樣本平均的變異數是單題變異數除以題數；各級也互相獨立，變異數可以直接相加：

      Var(p̂h) = σh² ÷ nh　　SE(T̂) = √( Σ Nh² · σh² ÷ nh )

      σh² 用你自己的作答估計（X² 的平均減去 X 平均的平方）。某一級全對或全不會時，樣本變異數會是 0，但這不代表毫無誤差，所以改用 (k + 0.5) ÷ (n + 1) 修正後的比例 p̃ 計算 p̃(1 − p̃)，避免範圍被低估。

      4. 95% 信賴區間（confidence interval）

      根據中央極限定理（central limit theorem），T̂ 是 60 個獨立得分的加權和，近似常態分布，所以結果頁的範圍是：

      T̂ ± 1.96 × SE(T̂)

      這就是高中數學學過的 95% 信賴區間：用同樣方法測很多次，約 95% 的區間會包含你真正的單字量。

      5. 樣本數與精確度

      SE 和 √n 成反比：題數變 2 倍，誤差變成 1/√2 ≈ 0.71 倍；變 3 倍，誤差變成 1/√3 ≈ 0.58 倍。所以 60 題約 ±500 字，120 題約 ±370 字，180 題約 ±300 字。每輪都抽沒考過的字，新的作答和前面的合併計算。

      6. 蒙地卡羅模擬驗證（Monte Carlo simulation）

      我們設定了國中程度、高一、高三、程度好四種學生，各自「誠實作答」和「不會就亂猜」，每種用電腦模擬數千次。結果：

      偏誤（平均估計值 − 真實值）：誠實作答與亂猜都在 ±10 字以內
      95% 信賴區間的實際涵蓋率（coverage）：93%–97%
      區間半寬：誠實作答 60 題約 ±500 字；亂猜 60 題約 ±800 字

      偏誤接近 0 驗證了第 2 點的不偏性；涵蓋率接近 95% 驗證了第 3、4 點的標準誤和信賴區間。

      題庫

      詞彙表（111 學年度起適用）每級隨機選出 150 個字作為題庫，共 900 字，可以連做 15 輪不重複。錯的選項是同一級、同詞性的字，意思和答案沒有重疊，不會有兩個都對的情況。估計的是「這 150 個字代表的整級」，題庫是隨機選的，所以能代表該級。

      模型假設與限制

      第 2 點假設不認得的字是四個選項平均亂猜。如果你會刪去法（刪掉一兩個選項再猜），猜對機率高於 1/4，分數會稍微偏高。另外，錯的選項刻意選了意思差很遠的字，比較好猜，也會讓結果略為偏高。測的是「看到英文知道中文意思」，不包括拼字、發音和用法。

      記憶曲線單字

      同樣的科學方法，用在記憶上

      這份測驗用分層抽樣和信賴區間估計你認得多少字。知道該補哪一級之後，下一步是記住；我們的 App「記憶曲線單字」用同樣講究證據的方法，決定每個字什麼時候該再考你。

      記憶模型
      FSRS：每個字追蹤難度 D、穩定度 S、記得的機率 R
      遺忘曲線
      R(t) = (1 + 19/81 · t/S)−0.5
      排程規則
      R 降到 90% 時安排複習

      圖 3　遺忘曲線示意。每次在 R 接近 90% 時複習（點），穩定度 S 變大，曲線下降得越來越慢；灰線為不複習的情況。

      間隔效應（spacing effect）是記憶研究中重複驗證最多的現象之一：分散複習比集中背誦記得更久。FSRS 是開源的記憶演算法，模型參數由大量真實複習紀錄擬合，可以公開檢驗。
